## Before using cleanup

Use MacUtility only on a Mac and files you are authorized to administer. Keep a current, tested backup and close affected apps before cleanup. Do not use cleanup on irreplaceable data without an independent backup.

Cleanup can cause data loss, lost diagnostics, interrupted applications, or other system problems. A Safe label describes normally rebuildable user caches or logs; it does not guarantee harmless removal. Review every selected item and its path. Classification and size estimates may be wrong or incomplete.

The default file-removal mode is Trash. Recovery is not guaranteed, and emptying Trash can make recovery impossible. Permanent deletion bypasses Trash. Administrator app removal may not support Finder's Put Back. Removing an application bundle does not remove all associated files.

Developer maintenance commands have their own consequences and can permanently remove resources or data, including Docker resources, regardless of the file-cleanup Trash setting. Review the displayed command and consequences before confirming it. Basic cache/log maintenance always uses Trash.

## Scans and estimates

Scanning reads reachable filesystem metadata without changing the scanned files. The app separately writes its local settings, history, and activity records. Permission failures, retained-record limits, and concurrent filesystem changes can limit results. Reported file sizes are not a promise of recoverable disk space, performance improvement, or recovery of deleted files.
